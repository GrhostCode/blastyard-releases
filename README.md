# BLASTYARD (downloads)

Physics sandbox FPS: sliding, leaning, 14 guns with 3-slot loadouts, explosive physics, 6 maps,
map editor, and multiplayer over Tailscale.

## Install

1. Download the newest `BLASTYARD-x.y.z-windows.zip` from **[Releases](../../releases/latest)**.
2. Right-click the zip → **Extract All** (don't run it from inside the zip).
3. Run `fps.exe`. If Windows says "Windows protected your PC", click **More info → Run anyway**
   (the game isn't code-signed).

The game updates itself: when a new version is out, the main menu shows **UPDATE NOW**.

## Play together (Tailscale)

1. Both install Tailscale (https://tailscale.com/download) and join the **same tailnet**
   (the host invites the other person's account, or shares their machine from the Tailscale admin page).
2. Host: **Multiplayer → Host Game**, then send the `100.x.x.x` IP shown there.
3. Friend: **Multiplayer → paste the IP → Join**.
4. First time hosting, if Windows asks about the firewall, click **Allow**.

Both players need the same version, so update first if the menu offers it.
Close Cheat Engine / debuggers before joining (the anti-cheat kicks for them).
